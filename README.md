## FAQ

**1. What is Apollo Save Tool?**

Apollo Save Tool is a PS4 homebrew application for managing game saves. It supports downloading, unlocking, patching, exporting, importing, and resigning supported save files directly on the console.

**2. Does Apollo Save Tool require GoldHEN?**

Since version 2.0.0, Apollo's PS4 application is firmware-agnostic and does not require GoldHEN, PS4HEN, or a ps4debug payload for its save-mounting functionality. A homebrew-enabled console is still necessary to install and run the application.

**3. Can Apollo Save Tool apply save-game cheats?**

Yes. It supports Save Wizard and Bruteforce Save Data patch formats, as well as custom patch functionality. Support depends on the relevant game, save format, and available patch definitions.

**4. Which virtual memory cards does it support?**

Apollo supports PS1 and PS2 virtual memory card images, and version 2.4.0 adds Dreamcast VMU image management. Import and export formats vary by platform.

**5. Where can I find the latest release?**

The official GitHub Releases page provides the current PKG package, release notes, and previous versions.
